The original root state-map JSON/CSV and handoff ZIP are preserved as prior research. The new analysis reconciles them against fresh source hashes and distinguishes confirmed structures/calls from inference and native unknowns. The prior handoff has conflicting version statements; use the new provenance notes when comparing builds.

Original game files, full strings and disassembler outputs are ignored private workspace data. Public-facing outputs are independently authored tools, documentation and compressed derived metadata. No mod has been built, deployed or published. Original game assets remain excluded from version control.
